Install hints

          
    
            
  1. Reader: plug in a PC/SC NFC reader (ACR122U, ACR1252U, PN532 kits work). Install pyscard on the machine running the bridge: pip install pyscard.
    2. 
            
  2. Bridge: run python3 bridge/openln-cardbridge.py --http and open this page, or install the Chrome extension for hands-free use from openln.com.
    3. 
            
  3. Extension: chrome://extensions → Developer mode → Load unpacked → pick the extension/ folder. The native host is registered by ./install.sh.
    4. 
          

          
Simulation mode lets you try everything before any hardware shows up.
